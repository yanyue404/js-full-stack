第二讲 · 用类型消灭非法状态

要回答的问题：一个异步请求的状态，用"可辨识联合"建模，能否从根上杜绝"既在加载又有报错""数据和错误同时存在"这类组合？和常见的三个布尔/可空字段写法相比差在哪？

PROTOTYPE · 一次性演示。左右两个模型接收完全相同的事件。可迁入真实代码的是 AsyncState（对应 useAsync hook）。

// 可辨识联合：每种状态只携带它该有的字段
type AsyncState<T> =
  | { status: 'idle' }
  | { status: 'loading'; attempt: number }
  | { status: 'success'; data: T }
  | { status: 'error'; error: string; attempt: number }

// 对照组：三个独立字段，可以组合出 2×2×2 = 8 种情况，其中大半是非法的
interface FlagsState<T> { isLoading: boolean; data?: T; error?: string }
