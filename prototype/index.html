全栈前端工程师 · 八讲逻辑原型

每一讲挑出一个"纸面上看起来没问题、推几步就容易出错"的状态模型，做成可以直接双击打开的单文件演示。不需要安装任何东西，也可以发给产品、设计同学一起点。

每个页面都分为：当前状态（蓝框表示刚刚变化的字段）→ 自由试玩（任意顺序点按钮）→ 引导式演练（预设的正常路径、边界情况和非法操作）。

第一讲 · React
待办事项的状态模型

派生数据该存还是该算？筛选 + 完成 + 清除组合下界面是否自洽。

 第二讲 · TypeScript
用类型消灭非法状态

可辨识联合 vs 三个布尔字段：重试、迟到响应时谁会出错。

 第三讲 · Node.js
双 Token 刷新与 RBAC

无感续期、越权 403、被盗 Refresh Token 重放检测。

 第四讲 · 数据库
事务、乐观锁与软删除

回滚不留残留，WHERE version = ? 拦住并发覆盖。

 第五讲 · Docker
启动顺序、健康检查与数据卷

service_healthy 的意义，down 与 down -v 的区别。

 第六讲 · AI
重试、降级、工具调用与上下文

429 重试、400 直接切换、全部失败兜底、按轮裁剪上下文。

 第七讲 · 混合开发
JS Bridge 回调表与超时

乱序回调、超时后迟到回调、版本兼容与 Web 降级。

 第八讲 · 生产实战
限流、熔断与降级

熔断器关闭 → 打开 → 半开的完整状态机，叠加限流与缓存降级。
